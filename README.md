# Quant Finance Playground

A place to learn mathematical finance by turning equations into code and checking what the results tell us.

## Explore a project

Each project lives in its own top-level folder and explores one idea or a set of related questions. Follow a project link for its methods, data, and run instructions. Each project chooses its own tools and dependencies.

[Monte Carlo stock risk](monte_carlo_risk/project.md) explores how diversification changes one-day value at risk and expected shortfall for a $10,000 investment. It starts with Apple alone and compares equal weighting with minimum-variance weighting across five stocks using simulated returns fitted to 2024 prices.

[Implied and realized volatility](implied_volatility/project.md) shows how an option price implies a volatility, how implied volatility varies across strikes, and how the VIX compares with S&P 500 volatility realized over the next 30 calendar days.

[Beyond Black–Scholes](black_scholes_extensions/project.md) compares how stochastic variance in Heston and price jumps in Merton change return distributions and prices of European calls. Simulated paths and implied volatility curves show how two different mechanisms can produce downside skew.
